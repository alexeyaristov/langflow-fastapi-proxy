# Подключение агента Langflow через FastAPI

Учебный сервис, который принимает числа, передаёт задачу умножения агенту Langflow и возвращает результат в JSON.

## Задача проекта

Предоставить внешний API для запуска агента. Такой сервис можно подключить к веб-форме, Telegram-боту или системе автоматизации.

## Мой вклад

На основе примера из курса настроил подключение к своему сценарию Langflow, протестировал запросы и добавил измерение времени обработки в ответ API и вывод терминала.

## Стек технологий

- Python — логика сервиса.
- FastAPI — HTTP-эндпоинты и документация.
- Pydantic — проверка входных данных.
- HTTPX — асинхронные запросы к Langflow.
- Uvicorn — запуск сервера.
- python-dotenv — загрузка локальных настроек.
- Langflow — выполнение сценария с агентом.

## Основные блоки

1. Загрузка адреса Langflow, Flow ID и API-ключа.
2. Проверка запроса: список должен содержать минимум два числа.
3. Преобразование чисел в выражение, например `6.0 * 8.0`.
4. Отправка запроса в Langflow.
5. Извлечение текста ответа и измерение времени обработки.
6. Возврат результата клиенту.

Умножение выполняется в сценарии Langflow, а не непосредственно в FastAPI.

## Установка и настройка

Команды для Windows PowerShell из папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Создайте в корне проекта файл `.env`:

```env
LANGFLOW_URL=http://127.0.0.1:7860
LANGFLOW_FLOW_ID=your_flow_id
LANGFLOW_API_KEY=your_langflow_api_key
LANGFLOW_INPUT_TYPE=chat
LANGFLOW_OUTPUT_TYPE=chat
CORS_ALLOW_ALL=false
```

Замените заглушки своими значениями. Настоящий `.env` с ключом не публикуйте.

Langflow должен быть запущен отдельно. Указанный Flow должен принимать текстовое выражение и возвращать результат умножения через Chat Output. Сам сценарий Langflow в этот репозиторий пока не включён.

Для внешнего веб-интерфейса дополнительно задайте разрешённый источник:

```env
LOVEABLE_ORIGIN=https://your-interface.example
```

Название `LOVEABLE_ORIGIN` должно совпадать с кодом.

## Запуск

```powershell
.\.venv\Scripts\python.exe -m uvicorn main:app --reload --port 8000
```

Откройте:

- документацию: http://127.0.0.1:8000/docs
- проверку сервиса: http://127.0.0.1:8000/health

## Запрос к API

Эндпоинт: `POST /multiply`

```json
{
  "numbers": [6, 8],
  "session_id": "portfolio-test-1"
}
```

- `numbers` — обязательный список минимум из двух чисел.
- `session_id` — необязательный идентификатор сессии. По умолчанию используется `multiply-session`.

## Формат ответа

Сервис возвращает:

- `input` — выражение, переданное агенту;
- `auth_used` — применённый способ авторизации в Langflow;
- `result_text` — текст результата или `null`, если текст не удалось извлечь;
- `processing_time_ms` — время успешной обработки запроса в миллисекундах;
- `raw` — полный JSON-ответ Langflow.

Время обработки также выводится в терминале.

## Проверка работы

1. Передать `[6, 8]` — получить ответ с результатом 48.
2. Передать `[6]` — получить ошибку валидации HTTP 422.
3. Проверить наличие `processing_time_ms` в успешном ответе.
4. Открыть `/health` — получить `{"status": "ok"}`.

Проверка `/health` подтверждает работу FastAPI, но не проверяет доступность Langflow.

## Статус и ограничения

Учебный прототип, протестированный локально.

Клиентская авторизация и ограничение частоты запросов пока не реализованы. Перед публичным использованием нужны защита API, ограничение входных данных, безопасная обработка ошибок и проверка качества ответов агента.

Без явно заданного `session_id` запросы используют общую сессию.
